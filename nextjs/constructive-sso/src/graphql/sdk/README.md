# Per-DB SDK Structure

This directory contains the generated GraphQL SDK (committed; regenerated by
`pnpm codegen` against the tenant's live hosts) plus this hand-written guide.
`index.ts` and `.targets` are generated root files — a regeneration rewrites
them; this README is preserved across runs by `scripts/codegen.sh`.

Two SDK contexts, each connecting to a different GraphQL endpoint:

## Contexts

| Context | Endpoint Pattern | Contains |
|---------|-----------------|----------|
| `admin` | `admin-{db}.localhost:80` | Organizations, members, permissions, invites |
| `auth` | `auth-{db}.localhost:80` | Users, emails, authentication |

There is no `app` context: this template's tenants have no business-data
tables, and the generator rejects an empty schema.

## Usage

```typescript
// Import from the appropriate context
import { useOrganizationsQuery } from '@sdk/admin';
import { useCurrentUserQuery, useEmailsQuery } from '@sdk/auth';
```
